# TikTok Hashtag Monitor

Monitor TikTok hashtags, topic clusters, and short-video patterns for trend research.

Inputs:

- `target`: hashtag, keyword, or topic
- `objective`: monitoring goal
- `language`: output language

Process:

1. Search the hashtag or topic through registered SDCenter tools.
2. Group visible content by hook, format, audience reaction, and creator type.
3. Highlight rising patterns, repeatable ideas, and risk themes.
4. Return a monitoring summary and follow-up queries.

Rules:

- Use only registered SDCenter tools.
- Mark missing trend evidence clearly.
- Do not make unsupported virality claims.
