## douyin-search-fetch_live_search_v2

`POST /api/v1/douyin/search/fetch_live_search_v2`

获取直播搜索 V2/Fetch live search V2

方法：`POST`。POST 使用 JSON 请求体；GET 使用 query。

| 位置 | 字段 | 必填 | 类型 / 默认 / 枚举 | 含义 |
| --- | --- | --- | --- | --- |
| body | `keyword` | 否 | string; default="小耳朵" | 抖音号 或 抖音昵称 / Douyin ID or nickname |
| body | `cursor` | 否 | integer; default=0 | 翻页游标，首次请求传 0，之后传上一页响应里的 cursor / Pagination cursor, 0 for the first request, then the cursor from the last response |

### 示例请求（不是实时成功响应）

```json
{
  "query": {},
  "body": {
    "keyword": "小耳朵"
  }
}
```

### 官方行为、分页与返回说明

# [中文]
### 用途:
- 按抖音号或抖音昵称搜索直播间（V2 版本），支持游标翻页。
- 适合定位某个主播的直播间，而不是按内容关键词泛搜直播。

### 备注:
- `keyword` 匹配的是主播的抖音号或昵称，传入内容类关键词（如 "游戏"）通常匹配不到结果。
- 本接口不支持排序、发布时间、时长等筛选条件。
- 每页固定 10 条，不支持指定数量。
- 首次请求 `cursor` 传 0，翻页时传上一页响应里返回的 `cursor`。

### 参数:
- keyword: 抖音号 或 抖音昵称（必填），如 "小耳朵"
- cursor: 翻页游标（首次请求传 0）

### 请求体示例：
```json
payload = {
    "keyword": "小耳朵",
    "cursor": 0
}
```

### 返回（部分常用字段，实际返回字段更多，一切以实际响应为准）:
- 匹配的直播间列表，每项包含主播昵称、抖音号、头像、直播间ID及开播状态等
- 翻页信息（下一页的 `cursor`、是否还有更多数据）

# [English]
### Purpose:
- Search live rooms by Douyin ID or nickname (V2), with cursor pagination.
- Best suited for locating a specific streamer's live room rather than searching live
  content by topic keyword.

### Notes:
- `keyword` matches the streamer's Douyin ID or nickname; a content keyword (e.g., "games")
  usually returns no result.
- This endpoint has no sorting, publish time or duration filters.
- Page size is fixed at 10 and cannot be changed.
- Set `cursor` to 0 for the first request, then pass the `cursor` from the previous response.

### Parameters:
- keyword: Douyin ID or nickname (required), e.g., "小耳朵"
- cursor: Pagination cursor (0 for the first request)

### Request Body Example:
```json
payload = {
    "keyword": "小耳朵",
    "cursor": 0
}
```

### Response (common fields, actual response may contain more fields):
- Matched live room list; each item contains the streamer's nickname, Douyin ID, avatar,
  room ID and live status
- Pagination info (next `cursor`, whether more results are available)
