- 快手热榜 V2 列表

## kuaishou-app-search_video_v2

`GET /api/v1/kuaishou/app/search_video_v2`

搜索视频V2/Search video V2

方法：`GET`。POST 使用 JSON 请求体；GET 使用 query。

| 位置 | 字段 | 必填 | 类型 / 默认 / 枚举 | 含义 |
| --- | --- | --- | --- | --- |
| query | `keyword` | 是 | string |  |
| query | `pcursor` | 否 | string; default="" | 首次留空，翻页传上一页响应的 pcursor / Empty for first page, pass pcursor from previous response |

### 示例请求（不是实时成功响应）

```json
{
  "query": {
    "keyword": "人工智能"
  },
  "body": null
}
```

### 官方行为、分页与返回说明

# [中文]
### 用途:
- 搜索视频 V2
- 此接口收费较贵，但稳定性更高，具体价格请在用户后台查看价格表。
### 参数:
- keyword: 搜索关键词
- pcursor: 分页游标，首次留空，翻页传上一页响应的 pcursor
### 返回:
- 视频数据

# [English]
### Purpose:
- Search video V2
- This API is more expensive, but more stable, please check the price list in the user background for specific prices.
### Parameters:
- keyword: Search keyword
- pcursor: Pagination cursor, empty for first page, pass pcursor from previous response
### Returns:
- Videos data

# [示例/Example]
keyword = "人工智能"
pcursor = ""
