# Kuaishou Content Trend

Track Kuaishou content trends, creator patterns, and audience reaction for planning workflows.

Inputs:

- `target`: keyword, topic, creator cluster, or video URL
- `objective`: trend research goal
- `language`: output language

Process:

1. Search available Kuaishou content through registered tools.
2. Summarize format patterns, comment themes, and audience cues.
3. Identify repeatable creative ideas and operational risks.
4. Return trend findings and next experiments.

Rules:

- Use registered SDCenter tools only.
