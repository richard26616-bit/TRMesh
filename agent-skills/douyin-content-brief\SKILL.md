# Douyin Content Brief

Analyze Douyin creators, videos, topics, and audience signals using registered SDCenter tools.

Inputs:

- `target`: creator, video URL, topic, or keyword
- `objective`: analysis goal
- `language`: output language

Process:

1. Resolve the Douyin target and collect available public data.
2. Summarize content format, hooks, engagement signals, and comment themes.
3. Identify reusable ideas, potential customer signals, and compliance risks.
4. Provide concise next actions.

Rules:

- Use only SDCenter registered tools.
- Do not bypass platform routing.
- Separate verified data from inference.
