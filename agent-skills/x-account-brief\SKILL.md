# X账号订阅追踪 / x-account-brief

## 简介

围绕 X 账号做画像、内容结构、增长信号和对标账号分析，输出账号诊断和下一步优化建议。

本技能仿照 RedFox 热门 Skill 的使用方式设计：用户只需要用自然语言描述目标、关键词、账号、日期或分析目的，Agent 负责选择已注册的 SDCenter 工具，完成数据查询、聚类、评分、风险提示和行动建议。

## 核心价值

- **真实数据驱动**：结论必须来自 SDCenter 已注册工具返回的数据，不用经验臆测替代证据。
- **面向运营交付**：输出不只停留在摘要，还要给出选题、账号、内容、投放或风控动作。
- **可复核来源**：关键判断要标注数据口径、样本范围、时间窗口和不可验证部分。
- **安全可控**：所有平台访问必须走 SDCenter 的受控链路，不直接请求外部 URL。

## 适用对象

- **内容运营 / 新媒体编辑**：快速获取热点、爆款结构和选题线索。
- **创作者 / MCN 团队**：对标账号和作品表现，形成可执行优化清单。
- **品牌 / 增长团队**：识别用户需求、舆情风险、达人机会和内容切入点。
- **研究 / 销售团队**：把平台讨论转成市场洞察、客户声音和跟进建议。

## 功能特性

- **目标识别**：自动判断用户输入是账号、作品、话题、关键词、榜单需求还是文案评分需求。
- **数据查询**：按平台、关键词、时间窗口、排序方式调用 SDCenter 注册工具。
- **热点聚类**：把相似作品、话题或评论合并成主题簇，避免只罗列原始数据。
- **证据摘要**：输出代表样本、互动指标、评论信号、增长变化和异常点。
- **行动建议**：给出下一步选题、标题、脚本、账号运营、达人合作或风险处理建议。

## 工具绑定

- `x.profile.lookup`
- `x.content.search`
- `x.account.benchmark`

如果所需工具未注册、被禁用或当前 API 目录不在线，停止执行并说明缺失能力；不要改为直接访问平台网页或第三方接口。

## 输入参数

| 参数 | 必填 | 说明 |
| ---- | ---- | ---- |
| `target` | 是 | 账号、作品链接、话题、关键词、社区、标题或正文 |
| `objective` | 否 | 用户的业务目标，例如选题、诊断、竞品、舆情、评分、改写 |
| `timeRange` | 否 | 时间范围，例如今日、近7天、指定日期 |
| `filters` | 否 | 地区、语言、互动阈值、账号类型、品类等筛选条件 |
| `language` | 否 | 默认输出中文；用户要求其他语言时再切换 |

## 输出结构

| 模块 | 内容 |
| ---- | ---- |
| 结论摘要 | 3-5 条最重要发现，区分事实和推断 |
| 数据依据 | 样本范围、时间窗口、关键指标、代表内容 |
| 主题/账号/评论拆解 | 按任务类型输出聚类、评分、画像或情绪结果 |
| 机会点 | 可复用选题、账号动作、达人/商品/社群线索 |
| 风险点 | 数据缺口、合规风险、负面舆情、样本偏差 |
| 下一步 | 3-7 条可执行建议，按优先级排序 |

## 使用指南

直接用自然语言描述需求，无需记忆命令。

### 常用说法速查

| 意图 | 示例话术 | 效果 |
| ---- | -------- | ---- |
| 诊断账号 | 「诊断这个X账号」 | 输出定位、内容结构和增长问题 |
| 对标账号 | 「和这3个竞品账号对比」 | 对比频率、互动和内容钩子 |
| 找改进点 | 「下周应该怎么优化内容」 | 给出行动清单 |

## 使用场景

| 场景 | 角色 | 交付结果 |
| ---- | ---- | -------- |
| 每日热点追踪 | 内容运营 | 热点日报、主题聚类、代表作品和选题建议 |
| 竞品/账号对标 | 创作者 / MCN | 内容结构、互动差距、爆款钩子和改进动作 |
| 舆情与评论复盘 | 品牌 / 客服 | 用户情绪、核心争议、需求词和风险等级 |
| 市场机会发现 | 增长 / 销售 | 人群痛点、潜在需求、可跟进话术和线索方向 |

## 执行规则

1. 只调用 SDCenter 已注册工具：
  - x.profile.lookup
  - x.content.search
  - x.account.benchmark
2. 不绕过 UpstreamGateway，不绕过 Billing，不绕过 Usage 日志。
3. 不编造播放量、点赞、评论、排名、账号粉丝量或任何平台指标。
4. 数据缺失时写明“未返回 / 不可验证 / 样本不足”，并说明会影响哪些结论。
5. 不输出或要求用户提供平台账号密码、Cookie、私信内容、未授权个人信息或敏感密钥。
6. 如果用户要求执行未注册外部请求，拒绝该部分并给出可通过 SDCenter 工具完成的替代方案。
